# Backup Directory

This directory is used to store system backup outputs, such as full site ZIP files or database exports. 

**Note**: All `.zip` files in this directory are excluded from version control to keep the repository lightweight.

---

# 備份目錄 (Backup)

此目錄用於存放系統備份輸出，例如全站壓縮檔 (ZIP) 或資料庫匯出檔。

**注意**：此目錄下的所有 `.zip` 檔案皆已排除在版本控制之外，以保持儲存庫的輕量化。
