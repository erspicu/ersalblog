# Static Assets Directory

This directory contains static files used by the blog's frontend.

- **`blog.js`**: The main application logic for dynamic rendering and SPA features.
- **`exif.js`**: A library used to read and display EXIF metadata from images.
- **`icon-192.png` / Favicons**: Branding and site icons.
- **Minified Files (`*.min.js`)**: Production-ready versions of scripts generated by `mini.py`.

The templates in `blog.html` and the generated static pages reference these assets.

---

# Static 靜態資源目錄

此目錄包含部落格前端使用的靜態檔案。

- **`blog.js`**: 用於動態渲染和 SPA 功能的主要應用程式邏輯。
- **`exif.js`**: 用於讀取並顯示圖片 EXIF 元資料的函式庫。
- **`icon-192.png` / Favicons**: 網站圖示。
- **壓縮檔 (`*.min.js`)**: 由 `mini.py` 生成的正式環境用腳本。

`blog.html` 中的範本以及生成的靜態頁面都會引用此目錄中的資源。
