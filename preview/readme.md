# Preview Images Directory

This directory stores preview images and icons for the blog posts.

- **`icon-[post_filename].jpg`**: These icons are automatically detected by `make_html.php` during the static page generation process to set the `og:image` and `twitter:card` meta tags.
- **`BaxerMuxBlog.jpg`**: Default site preview image.

These images are generally used for social media sharing and site-wide content previews.

---

# Preview 預覽圖目錄

此目錄存放部落格文章的預覽圖與圖示。

- **`icon-[文章檔名].jpg`**: 這些圖示在靜態頁面生成過程中會被 `make_html.php` 自動偵測，用於設定 `og:image` 與 `twitter:card` 等 Meta 標籤。
- **`BaxerMuxBlog.jpg`**: 網站預設的預覽圖片。

這些圖片主要用於社交媒體分享以及全站的文章內容預覽。
