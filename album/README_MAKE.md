# 相簿建置工具 (make_album.php) 使用說明

本工具負責掃描 `Collection/` 目錄，產生縮圖、JSON 資料以及短網址索引。

## 執行情境與指令

根據您的需求，請選擇對應的指令執行：

### 1. 完整重跑 (JSON + 縮圖強制更新)
當您修改了圖片處理邏輯，或想要確保所有檔案都是全新產生時使用。
```bash
php make_album.php -f
```

### 2. 標準建置 (JSON + 縮圖均使用快取)
最常用的模式。僅針對有變動的相簿更新 JSON，僅針對新照片或原圖有變動的照片產生縮圖。
```bash
php make_album.php
```

### 3. 強制完整建立 JSON (不處理縮圖)
當您修改了相簿註解或程式讀取 JSON 的結構，但不想花時間去動縮圖時使用。
```bash
php make_album.php --force-json -s
```

### 4. 快速建立 JSON (使用快取，不處理縮圖)
僅為了更新索引或總表，且確定縮圖不需要檢查時使用。這是最快的執行模式。
```bash
php make_album.php -s
```

### 5. 處理縮圖 (使用快取機制)
當您手動補了一些原圖進去，想要補齊縮圖，但不想變動現有的 JSON 快取判斷時。
```bash
php make_album.php
```
*(註：在標準模式下，系統會自動檢查並補齊缺失的縮圖)*

### 6. 強制重新產生所有縮圖 (使用 JSON 快取)
當您修改了 `compression.json` 中的品質設定，想要讓所有縮圖以新品質重跑，但相簿描述等資訊維持現狀時使用。
```bash
php make_album.php --force-thumb
```

## 參數說明表

| 參數 | 說明 |
| :--- | :--- |
| `-f`, `--force` | 強制所有項目重新產生（忽略所有快取）。 |
| `-s`, `--skip-thumb` | 跳過縮圖處理流程（僅處理 JSON 與索引）。 |
| `--force-json` | 強制重新產生 JSON 檔案。 |
| `--force-thumb` | 強制重新產生縮圖檔案。 |
| `-h`, `--help` | 顯示參數輔助說明。 |
