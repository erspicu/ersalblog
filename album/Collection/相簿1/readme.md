# 相簿資料規範說明 (Album Data Specification)

本目錄存放特定相簿的原始資源與描述檔。系統透過解析本目錄下的 `.txt` 檔案來呈現相簿內容。

---

## 1. 相簿元數據 (`comment_album.txt`)

此檔案定義相簿的整體資訊。

### 格式規範
`顯示標題|相簿詳細描述|封面照片檔名|建立日期`

### 範例
`東京三日遊|這是一段關於東京旅行的詳細背景故事描述...|IMG_20251021_150129.jpg|20260104`

### 預設行為 (Fallback)
若此檔案不存在，系統將自動套用以下規則：
- **顯示標題**: 使用「目錄名稱」。
- **相簿描述**: 留空。
- **封面照片**: 使用目錄內的第一張照片。
- **建立日期**: 使用目錄的實體建立時間。

---

## 2. 照片詳細描述 (`comment_pic.txt`)

此檔案定義相簿內各張照片的個別標題與描述。

### 格式規範
`檔案名稱|照片標題|照片內容描述`

### 範例
```text
IMG_20251021_150129.jpg|東京的烏鴉|去東京玩看到好多烏鴉，體型非常巨大。
IMG_20251021_154053.jpg|東京公園|公園裡的悠閒午後。
IMG_20251021_204714.jpg|東京夜景|從觀景台望出去的繁華燈火。
```

### 預設行為 (Fallback)
若某張照片未在檔案中定義：
- **照片標題**: 使用「檔案名稱」。
- **照片描述**: 留空。

---

## 3. 資源目錄 (`Thumbnail/`)

此目錄由系統生成，存放不同解析度的預覽縮圖，請勿手動修改其中的內容。
縮圖命名遵循 `FILENAME_[Prefix].EXTENSION` 規則，以確保檔案排序與管理的一致性。
