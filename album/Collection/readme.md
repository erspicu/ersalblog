# Album Data Architecture (相簿數據架構)

本目錄是相簿系統的「檔案式資料庫」，採用去中心化設計，每個相簿目錄皆為一個獨立的單元。

## 目錄設計規範
每一層子目錄代表一個「相簿」，其目錄名稱即為該相簿的實體識別碼 (ID)。

### 1. 相簿描述檔 (`comment_album.txt`)
位於每個相簿目錄下，定義相簿元數據。
**格式：** `顯示標題|相簿描述|指定封面檔名|建立日期`
- 若不存在，系統將以目錄名作為標題，並以第一張照片作為封面。

### 2. 相片描述檔 (`comment_pic.txt`)
定義該相簿內各張照片的細節。
**格式：** `檔案名稱|照片標題|內容描述`
- 若不存在，系統將以檔名作為顯示標題。

### 3. 縮圖目錄 (`Thumbnail/`)
(Git 忽略) 由 `make_album.php` 自動生成，存放多種規格的預覽圖。
**命名規則：** `FILENAME_[Prefix].EXTENSION`
- `_thumb`: 800px (列表預覽)
- `_thumbM`: 1024px (分享/社群用)
- `_thumbL`: 1600px (詳情頁主圖)
- `_thumbXL`: 2048px (Modal 全螢幕，原圖若小於此尺寸則直接複製)

## 開發理念
這種「基於檔案系統」的設計，確保了相簿內容的高度可移植性與獨立性，無需依賴 SQL 資料庫即可實現完整的靜態生成 (SSG) 與動態讀取。
