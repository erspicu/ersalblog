# 當週歷史紀錄 - 2026 第 07 週 (繁體中文)

## [2026-02-09]
### 新增
- **相簿服務：Y2K 主題**：建立了「土氣」的復古 2000 年代風格主題 (`album-y2k.css`)，具備深藍色背景、青色/洋紅色調及 Windows 95 風格的 UI 元件。
- **相簿服務：駭客任務主題強化**：在 `album-matrix.css` 中加入了純 CSS 實作的「數位雨」特效，支援多層次掉落字元（日文、符號、二進位），並針對 4K 螢幕進行滿版優化。
- **前端主題插件機制**：在 `album_template.html` 中實作了動態載入 `{theme}.js` 的機制，允許每個主題擁有獨立的互動邏輯。
- **相簿服務：Y2K 插件**：建立了 `album-y2k.js`，包含復古的 Alert 歡迎詞、姓名輸入打招呼功能，以及 Windows 95 風格的音樂播放器介面。
- **背景音樂整合**：在主題插件中整合了 YouTube IFrame API，支援隱藏式背景音樂播放功能。
- **後台設定**：在相簿管理後台的佈景主題選單中加入了 `album-y2k` 選項。

### 變更
- **Git 設定**：更新 `.gitignore`，明確允許追蹤 `album/static/` 目錄下的所有素材檔案 (GIF, JS, CSS)。
- **素材本地化**：下載並本地化了經典的「施工中 (Under Construction)」GIF，確保穩定性並避免外部連結失效。
- **相簿產生器**：更新 `make_album.php` 的輸出邏輯，以包含新的主題插件載入器。
