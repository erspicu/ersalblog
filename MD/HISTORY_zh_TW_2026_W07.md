# 當週歷史紀錄 - 2026 第 07 週 (繁體中文)

## [2026-02-10]
### 新增
- **Blazor WASM 相簿總管 (實驗性)**：在 `album/BlazorAlbumExplorer` 下建立了一個全新的實驗性專案，使用 Blazor WebAssembly 實作。
- **WinForms/WPF 介面風格**：使用 HTML/CSS 成功模擬了 Windows 檔案總管與視窗系統的操作體驗。
- **功能特性**：
    - **桌面環境**：具備工作列、開始選單、系統匣 (System Tray) 與動態時鐘。
    - **視窗管理**：實作了完整的視窗拖曳、最大化/最小化、前後景層級 (Z-Index) 切換。
    - **檔案瀏覽**：可讀取 `api/json/` 資料，以 Windows 11 風格的資料夾圖示顯示相簿清單，並支援預覽圖。
    - **相片檢視器**：內建獨立視窗的相片檢視器，支援滑鼠點擊 (左/右鍵) 與鍵盤方向鍵切換照片。
    - **幻燈片模式**：支援全螢幕幻燈片播放，並可隨時按 ESC 退出。
    - **資訊面板**：整合 EXIF 資訊與 Google Maps 嵌入顯示。
    - **相片編輯模擬**：實作了順時針/逆時針旋轉功能 (CSS Transform)。
- **Windows 11 視覺優化**：
    - **精緻資料夾**：使用 CSS 繪製了具有層次感、陰影與內容預覽的 Win11 風格資料夾圖示。
    - **微圓角設計**：視窗與對話框採用標準的 8px 圓角設計。
    - **MessageBox**：實作了標準的 Windows 訊息對話框作為開始選單的資訊展示。

## [2026-02-09]
### 新增
- **相簿服務：Y2K 主題**：建立了「土氣」的復古 2000 年代風格主題 (`album-y2k.css`)，具備深藍色背景、青色/洋紅色調及 Windows 95 風格的 UI 元件。
- **相簿服務：駭客任務主題強化**：在 `album-matrix.css` 中加入了純 CSS 實作的「數位雨」特效，支援多層次掉落字元（日文、符號、二進位），並針對 4K 螢幕進行滿版優化。
- **前端主題插件機制**：在 `album_template.html` 中實作了動態載入 `{theme}.js` 的機制，允許每個主題擁有獨立的互動邏輯。
- **相簿服務：Y2K 插件**：建立了 `album-y2k.js`，包含復古的 Alert 歡迎詞、姓名輸入打招呼功能，以及 Windows 95 風格的音樂播放器介面。
- **背景音樂整合**：在主題插件中整合了 YouTube IFrame API，支援隱藏式背景音樂播放功能。
- **後台設定**：在相簿管理後台的佈景主題選單中加入了 `album-y2k` 選項。

### 變更
- **Git 設定**：更新 `.gitignore`，明確允許追蹤 `album/static/` 目錄下的所有素材檔案 (GIF, JS, CSS)。
- **素材本地化**：下載並本地化了經典的「施工中 (Under Construction)」GIF，確保穩定性並避免外部連結失效。
- **相簿產生器**：更新 `make_album.php` 的輸出邏輯，以包含新的主題插件載入器。
## [2026-02-11]
### 變更
- **相簿服務：移除 Win11 主題**：從專案中完全移除了 `album-win11` 主題，包括 CSS 樣式、JavaScript 插件及相關素材。
- **前端設定**：將 `config.js` 的預設主題恢復為標準版 `album`。

- **環境清理**：移除了專案目錄下的暫存檔 `(backup)config.php` 與測試用的截圖 (`qa1.png`, `qa3.png`)。
- **Blazor 修正**：清理了 `BlazorAlbumExplorer` 因遞迴發佈產生的極深嵌套目錄 (`bin`, `obj`, `publish`)，並在 `.gitignore` 中加入相關忽略規則以防再次發生。
