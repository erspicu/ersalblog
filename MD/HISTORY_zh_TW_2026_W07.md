# 當週歷史紀錄 - 2026 第 07 週 (繁體中文)

## [2026-02-11]
### 新增
- **相簿服務：Win11 主題 (真・Blazor 移植)**：放棄 CSS 模擬，改採全屏嵌入編譯後的 Blazor WASM 引擎。
    - **技術端整合**：將 Blazor 專案正式發佈至主題目錄 `dist/`，並透過 `theme.js` 插件進行全自動載入。
    - **原生水印**：直接在 Razor Layout 中實作「啟動 Experimental Project」水印，並整合內建的 **Edge 瀏覽器模擬器** 展示技術白皮書。
    - **技術白皮書**：於虛擬 Edge 中加入深度的 C# 代碼解說（DI, JS Interop, HttpClient）與未來專業化願景（邊緣影像處理、加密容器）。
- **相簿服務：主題選擇器 (`ThemeSelect.html`)**：建立了一個獨立的主題預覽頁面，採用現代化卡片式 UI，動態呈現所有可用的相簿風格。
- **主題清單 API**：實作了 `api/api_themes.php` 以自動掃描主題目錄並回傳 JSON 格式列表。
- **全域下載管理器 (`DownloadManager`)**：在 `album.js` 中實作了具備併發控制的資源管理器。
    - **併發控制**：限制同時下載/載入任務最多為 3 個，優化頻寬分配並避免瀏覽器請求阻塞。
    - **事件驅動 EXIF**：修正了併發下載下的 EXIF 解析競爭問題，改採事件監聽機制，確保技術資訊在照片載入後精準呈現。

### 修正
- **Blazor 修正**：清理了 `BlazorAlbumExplorer` 因遞迴發佈產生的極深嵌套目錄 (`bin`, `obj`, `publish`)。
- **Git 優化**：在 `.gitignore` 中加入 .NET 編譯產物忽略規則，防止倉庫膨脹。
- **路徑自動適配**：修正了 Blazor 在 Apache 子目錄環境下的資源讀取層級（從 3 層修正為 5 層），確保 JSON 與圖片載入正常。
- **環境清理**：移除了專案目錄下的暫存檔 `(backup)config.php` 與測試用的截圖 (`qa1.png`, `qa3.png`)。

## [2026-02-10]
### 新增
- **Blazor WASM 相簿總管 (實驗性)**：建立實驗性專案，使用 Blazor WebAssembly 模擬 Windows 檔案總管與視窗系統操作體驗。
