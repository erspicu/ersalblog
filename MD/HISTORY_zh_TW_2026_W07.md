# 當週歷史紀錄 - 2026 第 07 週 (繁體中文)

## [2026-02-13]
### 新增
- **語系自動偵測**：`install.php` 與 `login.php` 現在會自動掃描 `langs/` 目錄，動態生成可用的語系選單，無需手動修改程式碼即可擴充語言。
- **設定檔結構同步**：更新 `config.example.php` 以包含完整的 SEO、預覽圖及全域變數設定，與安裝精靈產出的格式保持一致。
- **後台多語系支援框架**：實作相簿後台完整多語系架構，支援中英切換。建立 `langs/` 目錄統一管理翻譯檔，並在登入頁面提供即時語系預覽切換功能。
- **相簿建置工具 (make_album.php) 強大化**：
    - **ID 永久穩定性**：現在會持久化儲存短網址 ID，確保照片順序變動或相簿重建時，已分享的連結永遠有效。
    - **參數化執行**：支援 `--only-html`, `--force-json`, `--force-thumb`, `-s` 等精細化指令，滿足各種快速建置情境。
    - **原子化檔案寫入**：實作安全寫入機制，防止因建置中斷導致的 JSON 或索引檔損壞。
- **安裝精靈 (install.php) 升級**：完整支持多語系介面與 HTML5 自定義表單驗證提示。同步加入 SEO 描述、相簿簡介、預覽圖及並行下載限制等初始化設定。
- **全域設定優化**：後台設定介面全面改用 AJAX 儲存並整合 SweetAlert2 提示，時區設定改為直覺的下拉選單。

### 修正
- **樣板路徑硬編碼**：將 `album_template.html` 內的所有靜態資源路徑寫死為相對路徑，解決主題 CSS 在部分情境下解析錯誤的問題。
- **EXIF 解析還原**：修復建置過程中遺漏的 GPS 與技術資訊提取邏輯，恢復地圖與相機參數顯示。

## [2026-02-12]
### 新增
- **後端與 SEO 設定介面**：後台新增對 `config.php` 的管理功能，可自定義網站標題、SEO 描述、OG 預覽圖、網站語系及系統時區。
- **動態樣板渲染 (SEO)**：`album_template.html` 現在全面支援動態 SEO 與 OG 標籤代入，提升社交分享效果。
- **並行下載限制設定**：後台前端設定新增「並行下載限制 (Concurrent Downloads)」參數，可自定義同時下載照片資源的最大數量，優化載入穩定性與伺服器負擔。
- **後台儀表板磁碟資訊**：儀表板新增磁碟空間監控，可即時查看系統總空間、可用空間、磁碟使用率，以及照片庫 (Collection) 的實際實體佔用大小。
- **相簿資料快取機制**：`make_album.php` 實作了 JSON 生成快取。若相簿內容、註解與縮圖配置未變動，將直接複用現有 JSON，大幅優化包含大量照片時的重建速度。
- **縮圖生成快取機制**：`make_album.php` 現在會判斷縮圖修改時間是否晚於原圖，若縮圖已存在且較新則跳過生成，大幅提升重建效率。
- **孤立縮圖自動清理**：重建相簿時會自動偵測並移除 `Thumbnail` 目錄中已失去原始檔案對應的縮圖。
- **動態縮圖配置載入**：前端分享功能現在會自動讀取 `compression.json` 的定義，動態產生對應的尺寸選項、標籤（Comment）與短網址 ID，不再需要硬編碼於 JS 中。
- **相簿服務：Win11 主題 (AOT 極致優化版)**：成功啟用 **AOT (Ahead-of-Time)** 編譯技術，將 C# 直接編譯為 WebAssembly 原生機器碼，大幅提升渲染效能與反應速度。
- **虛擬 Edge 瀏覽器升級**：在技術白皮書中新增 **AOT 編譯技術專章**，包含專案設定展示與效能提升分析。
- **沉浸式投影片模式**：實作投影片播放時自動隱藏任務列（Taskbar），使照片能真正覆蓋 100% 螢幕區域。
- **安全性強化**：後台登入與儀表板新增 `install.php` 殘留檢測。
- **相簿服務：時區設定**：安裝精靈新增系統時區選擇。

### 修正
- **相簿分享服務 (shorturl.php) 精度修復**：修復 PHP `fmod` 在大數運算時產生的精度損失，解決短網址分享時無法正確導向縮圖的问题。
- **分享連結配置同步**：更新 `album.js` 與 `admin/assets/js/album_selector.js`，使其縮圖後綴、偏移量及資料讀取邏輯與最新的 `compression.json` 配置完全一致。
- **視窗系統優化**：
    - **層級統一**：重構 `z-index` 管理系統，修正視窗前後景切換衝突。
    - **拖拽穩定性**：改用相對位移計演算法，徹底修復 Blazor 渲染導致的視窗跳轉問題。
- **路徑自動適配**：修正 Blazor 在子目錄下的資源層級問題。
- **設定檔集中化**：建立 `album/config/` 統一管理。
