# Vibe Coding 歷史紀錄 (2026_W06)

記錄本專案透過 Gemini CLI 進行 Vibe Coding 的開發歷程。

---

## [v2026.02.09.01.35] - 2026-02-09 (繁體中文)

### 相簿影像與地理資訊強化 (Imagery & Geolocation Enhancement)
- **縮圖品質優化**: 整合 ImageMagick (Imagick) 支援，實作高品質重新採樣與 EXIF 資訊保留，並具備 GD 自動回退機制。
- **EXIF 多層級備案**: 建立「官方 Extension > 前端 JS」的可靠解析架構，優化圖片載入偵測 (onload) 邏輯，確保各類環境下的資訊呈現穩定性。
- **GPS 地圖整合**: 實作地理座標解析與 Google Maps 嵌入功能，支援顯示緯度、經度文字及 360px 高度之互動式預覽地圖。
- **佈局重構**: 根據使用者示意圖調整詳情頁，實現 EXIF 垂直列表與地圖的 50/50 左右分割佈局，並加入響應式垂直堆疊邏輯。

## [v2026.02.08.22.52] - 2026-02-08 (繁體中文)

### 系統優化與介面打磨 (System Polish)
- **資料夾選擇器**: 實作後台資料夾選擇 Modal，支援層級瀏覽與快速選取，簡化相簿路徑設定流程。
- **防呆機制**: 強化 `settings.php` 儲存邏輯，強制檢查分頁數量有效性與相簿路徑正確性，並支援「清空」操作以停用整合。
- **多語系補全**: 全面補齊相簿服務相關介面（按鈕、提示、狀態訊息、文章編輯器選項）的中英文翻譯。
- **相簿入口**: 在 `album/` 目錄建立 `index.html` 跳轉頁，提供更直覺的目錄進入點。

## [v2026.02.08.20.36] - 2026-02-08 (繁體中文)

### 相簿服務深度整合 (Album Service Integration)
- **路徑靈活性**: 在 `config.php` 引入 `$album_path`，支援靈活的相對路徑設定（如 `album/` 或 `../album/`）。
- **健康偵測**: 實作相簿服務健康檢查邏輯，並整合至部落格後台儀表板，提供即時狀態顯示與管理入口。
- **編輯器整合**: 文章編輯器整合相簿挑選功能，支援動態路徑與跨目錄圖片顯示，並實作 API 端路徑自動修正。
- **設定頁面重構**: 重構 `admin/settings.php`，將後端核心設定 (config.php) 與前端介面設定 (config.js) 拆分為獨立表單與儲存按鈕，提升管理安全性。
- **穩定性修復**:
  - 修復分頁設定為 0 時導致的 API 除以零錯誤與前端 JSON 解析失敗。
  - 修正正則替換邏輯，改用 `${1}` 語法避免數字與反向引用衝突導致的 `config.php` 格式損壞。
  - 強化 `StaticGenerator.php` 的路徑修復邏輯，確保靜態文章在各種部署目錄下均能正確顯示相簿圖片。

## [v2026.02.08.14.00] - 2026-02-08 (繁體中文)

### 相簿管理後台 (Album Admin Panel)
- **獨立後台建置**:
  - 建立 `album/admin/` 獨立管理介面，實作完整 CRUD 功能 (新增/編輯/刪除相簿與照片)。
  - 整合部落格後台儀表板，自動偵測並提供相簿管理入口。
- **功能特性**:
  - **設定管理**: 新增前端設定頁面，可直接修改 `config.js` (主題、API 模式、每頁筆數)。
  - **圖片管理**: 支援批次上傳、封面設定、檔名修改與標題描述編輯。
  - **介面優化**: 採用 8 欄位寬螢幕佈局，統一預覽圖為「等比例縮放 (Contain)」模式。
  - **效能優化**: 實作 `thumbXS` (320px) 極小縮圖，大幅提升後台載入速度。

### 相簿服務 (Album Service) 架構重構
- **SPA 全面轉型**:
  - 移除舊版靜態 HTML 生成邏輯 (`view/`)，全面轉向 JSON 資料驅動的 SPA 架構。
  - 實作前後端分離的分頁機制：`json` 模式由前端處理，`api_filebase` 模式由後端 API 動態切片。
- **系統優化**:
  - 修正 API 在處理 URL 編碼與非 UTF-8 目錄名稱時的路徑錯誤。
  - 統一 `config.js` 與 `config.example.js` 設定結構。
  - 改進日期讀取邏輯：優先讀取描述檔，若無則自動回退至檔案系統時間。

## [v2026.02.08.03.15] - 2026-02-08 (繁體中文)

### 相簿服務 (Album Service) 優化
- **短網址系統 (ShortURL)**:
  - 實作 `album/shorturl.php`，支援 Base62 編碼與 MIME Type 自動辨識回傳。
  - 升級混淆演算法：採用 **模乘雜湊 (Modular Multiplicative Hashing)** + XOR 掩碼，產生高度隨機的 5 碼 Slug。
  - 生成器整合：`make_album.php` 現在會自動生成 `shorturl.txt` (格式：`ID|Path`) 供反查使用。
- **前端重構 (De-Bootstrap)**:
  - **移除依賴**: 完全移除 Bootstrap CSS/JS 框架，改用原生 HTML/CSS/JS 實作。
  - **CSS Grid**: 重寫 `album/static/album.css`，採用 modern CSS Grid 進行響應式佈局。
  - **輕量化**: 整合並內聯 SVG 圖示，移除所有外部字體與多餘資源，大幅提升載入速度。
- **多重主題 (Theme System)**:
  - 建立主題切換機制，支援 `album` (預設), `album-dark`, `album-pink`, `album-matrix` 四種風格。
  - 新增 `album/config.js` 與 `config.example.js` 供使用者自訂預設主題。
- **功能增強**:
  - **原始檔下載**: 在詳情頁新增下載按鈕，直接連結至 Collection 下的高品質原圖。
  - **進階分享**: 實作多尺寸連結分享視窗，支援一鍵複製與「原始路徑/短網址」切換功能。
  - **導覽優化**: 統一全站分頁導覽列為置中顯示，修正標頭與內容寬度對齊問題。
  - **EXIF 顯示**: 前端移除 `exif.js`，改由後端 PHP 讀取並直接渲染至靜態 HTML，提升相容性與效能。
- **系統維護**:
  - 更新 `.gitignore` 排除敏感設定檔與生成數據。
  - 清理舊規則縮圖並強制重建所有靜態資源。
  - 更新 `album/Collection/相簿1/readme.md` 規範。
